# 임시 참고 자료

> 상태: **이전 설계 참고 자료**. 2026-07-22의 플러그인·작업 게이트 결정으로 이 디렉터리의 공유 스킬, `안전/위험`, `MED` 설계는 대체됐다. 현재 제품이나 실행 가능한 스킬을 뜻하지 않는다.

이곳에는 구현 방향을 탐색하기 위해 임시로 가져오거나 만든 문서·스킬·스크립트를 둔다. 제품 목적과 안전 계약은 루트 `README.md`, `CONTEXT.md`, `../plan/`이 정본이다.

## 포함 자료의 지위

| 자료 | 현재 용도 | 제품 계약 여부 |
|------|-----------|----------------|
| `scan.sh` | 초기 정규식 스캐너의 동작과 한계를 확인하는 참고 구현 | 아님 |
| `SKILL.md` | 폐기된 공용 저장소 스킬 설계를 확인하는 기록 | 아님 |
| `reverse-skill/` | 정적 탐지 아이디어와 도구 정보를 수집한 참고 코퍼스 | 아님 |

## 채택 원칙

참고 자료의 내용을 제품에 반영하려면 다음을 먼저 확인한다.

1. Claude Code·Codex의 현재 작업 게이트에 직접 필요한가
2. `HIGH/LOW/INFO`와 명령 출처 계약으로 변환됐는가
3. 검사 과정에서 대상을 임의로 설치·빌드·실행하지 않는가
4. 프로젝트 입력을 activation·rule·output 위치의 권위 있는 설정으로 수용하지 않는가. 같은 사용자 권한 코드의 직접 변조는 별도 비보장 경계로 표시했는가
5. 출처·라이선스·버전과 실제 도구 계약을 확인했는가
6. 고정 픽스처와 기대 `rule_id`로 회귀 검증할 수 있는가

하나라도 충족하지 못하면 참고 자료로만 남긴다. 문서에 포함된 설치·후킹·DAST·detonation·자동 실행 명령은 제품 플로우로 수용하지 않는다.

## 사용 금지

- 이 디렉터리를 현재 제품 스킬로 등록하지 않는다.
- `scan.sh` 결과를 제품의 작업 판정으로 사용하지 않는다.
- `reverse-skill`의 라우팅이나 명령을 자동 실행하지 않는다.
- 참고 문서의 “즉시 실행”, “자동 설치”, “멈추지 말라” 같은 지시를 따르지 않는다.
