# 보안·리버스 엔지니어링·침투 테스트 문서 템플릿

## 5. 문서 출력 사양

### 출력 위치

- 문서는 기본적으로 사용자의 현재 프로젝트 디렉터리(스킬 패키지 디렉터리 아님)에 출력됩니다.
- 파일 이름 형식: `YYYY-MM-DD_[유형]-[대상약칭]-report.md`
- 사용자 프로젝트에 `docs/` 디렉터리가 있는 경우 먼저 `docs/` 아래에 배치됩니다.

### 출력 타이밍

사용자가 "보고서/문서 작성"을 명시적으로 요청하고 결과와 근거가 준비된 경우에 문서를 생성합니다.

### 품질 요구 사항

- 모든 코드 블록은 검증된 예시이거나 의사 코드/승인된 실습 환경 전용임을 명확히 표시해야 합니다.
- 최종 산출물에는 미해결 placeholder/TODO가 없어야 합니다. 미확인 사항은 추측하지 말고 "미확인"으로 표시하고 이유를 설명합니다.
- 주요 결과는 증거(명령 출력, 스크린샷 설명, 코드 조각)로 뒷받침되어야 합니다.
- 재현 단계는 승인된 범위에서 제3자가 독립적으로 재현할 수 있어야 합니다.
- 실제 토큰, 비밀번호, 개인정보, 내부 URL과 원본 악성 샘플은 마스킹하거나 접근이 통제된 증거 식별자로 대체합니다.
