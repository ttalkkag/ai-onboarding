| ASI09 | 인간-에이전트 신뢰 악용| 위험한 작업을 승인하기 위해 작업자를 조작하는 행위| 권위 편향/긴급성 테스트|
| ASI10 | Rogue Agents | 에이전트 자체 복제/지속적인 악의적 행위| 지속성 백도어 탐지|

## 주요 방어 원칙

1. 계획과 실행의 분리 — 의도를 해석하는 모델 ≠ 행동을 실행하는 모델
2. ID/목적/범위/수명 바인딩 — 광범위한 환경 권한을 사용하지 않습니다.
3. 도구 호출/메모리/통신을 핵심 보안 텔레메트리로 기록합니다.
4. 폭발 반경 제어 - 회로 차단기/롤백/비상 정지로 안전성과 복구 가능성을 우선합니다.
5. 모든 자연어 입력(검색 콘텐츠 포함)은 신뢰할 수 없는 것으로 간주됩니다.
6. 출력도 신뢰할 수 없습니다. 렌더링/실행/쿼리 전에 정리하세요.
