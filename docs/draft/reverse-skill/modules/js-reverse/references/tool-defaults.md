# 도구 기본값

- `js-reverse_list_network_requests`: 첫 번째 페이지의 기본 결과를 먼저 살펴보고, 부족하면 다음 페이지로 넘어갑니다.
- `js-reverse_search_in_sources`: 기본값 `excludeMinified=true`
- `js-reverse_get_script_source`: 작은 조각만 읽고 전체 소스 코드에 우선순위를 부여하여 `js-reverse_save_script_source`과 협력합니다.
- `js-reverse_break_on_xhr`: 안정적으로 히트할 수 있는 URL 조각만 입력하세요.
- `js-reverse_get_paused_info`: 기본적으로 `frameIndex=0`를 먼저 봅니다.
